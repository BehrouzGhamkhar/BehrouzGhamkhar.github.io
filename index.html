Robotics & Machine Learning


VR-Based Human Feedback for Interactive Reinforcement Learning

Master's R&D project at H-BRS. Trained a simulated Pepper robot to choose context-appropriate social greetings from human body cues, connecting a Unity ML-Agents simulation to a Python/PyTorch RL backend. Implemented PPO and COACH (human-in-the-loop) and ran a 30-run hyperparameter sweep; with only 164 human feedback events, COACH fine-tuning raised policy entropy from 1.39 to 1.79 bits and HandShake selections 6.85×. Feedback comes from a VR interface that fuses controller input, head gestures and voice commands into a reward signal.

Multi-Robot Task Distribution for Warehouse Automation

Team project for the Software Development Project at H-BRS: a ROS2 Humble system in which a fleet of TurtleBot3 robots in Gazebo fetches and delivers warehouse orders using Nav2, with a Flask web GUI for placing orders and monitoring the fleet. As the largest contributor, I built the Task Manager, which scores idle robots by proximity and battery level and handles multi-product orders, and the Shared Memory node for inventory, drop-off stations and updates from robot feedback. I also built centralized logging with batched, asynchronous writes and a circular buffer, which fixed CPU and browser performance issues.
